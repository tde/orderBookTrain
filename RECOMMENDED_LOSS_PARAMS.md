## 🎯 Рекомендации (3 варианта)

### Вариант 1: Консервативный (начать с этого)

```python
# В src/config.py, класс ModelConfig:

```

**Когда использовать:** Первая попытка, хотите плавного улучшения.

---

### Вариант 2: Агрессивный (для максимальной точности на редких классах)

```python
focal_alpha = [25.0, 1.0, 25.0]       # Максимальный вес редких классов
focal_gamma = 4.5                      # Сильная фокусировка на сложных
focal_alpha_weight = 0.5               # Больший вес focal компоненты
cost_weight = 2.5                      # Высокая стоимость ошибок
```

**Когда использовать:** Нужна максимальная точность на up/down, можно пожертвовать немного общей accuracy.

---

### Вариант 3: Сбалансированный (золотая середина)

```python
focal_alpha = [22.0, 1.0, 22.0]       # Средний вес
focal_gamma = 4.0                      # Средняя фокусировка
focal_alpha_weight = 0.4               # Средний вес focal
cost_weight = 2.0                      # Средняя стоимость
```

**Когда использовать:** Баланс между общей точностью и точностью на редких классах.

## 📐 Формулы для расчета focal_alpha

### Метод 1: Inverse Frequency

```python
import numpy as np

counts = np.array([6596, 128575, 6694])
focal_alpha = counts.max() / counts

# Результат: [19.5, 1.0, 19.2]
```

### Метод 2: Effective Number of Samples

```python
beta = 0.9999  # для очень сильного дисбаланса
effective_num = 1.0 - np.power(beta, counts)
focal_alpha = (1.0 - beta) / effective_num

# Результат: примерно [20-25, 1.0, 20-25]
```

## 🔬 Как настроить под вашу задачу

### Шаг 1: Определите приоритет

**Вопрос:** Что важнее?

A) **Не пропускать движения** (up/down) → используйте **Агрессивный вариант**
   - Финансовая торговля: каждая упущенная возможность = потеря денег
   
B) **Не давать ложных сигналов** → используйте **Консервативный вариант**
   - Критичны ложные срабатывания
   
C) **Баланс** → используйте **Сбалансированный вариант**

### Шаг 2: Экспериментируйте

```python
# Запустите обучение с разными вариантами
# Сравните метрики:

# 1. Macro F1-score (среднее по классам)
# 2. F1 для класса 0 и 2 (up/down)
# 3. Confusion matrix
```

### Шаг 3: Тонкая настройка

Если модель:
- **Переобучается на редких классах** → уменьшите `focal_alpha` и `cost_weight`
- **Игнорирует редкие классы** → увеличьте `focal_alpha` и `cost_weight`
- **Слишком консервативна** → увеличьте `focal_gamma`
- **Слишком агрессивна** → уменьшите `focal_gamma`

## ⚠️ Важные замечания

1. **Не используйте слишком большие веса одновременно**
   - Если `focal_alpha` очень большой, не ставьте `cost_weight` тоже очень большим
   - Модель может переобучиться на редких примерах

2. **Мониторьте confusion matrix**
   ```python
   # После обучения проверьте:
   # - Не предсказывает ли модель все как flat?
   # - Какие ошибки делает чаще: down→up или up→down?
   ```

3. **Используйте BalancedBatchSampler**
   - Ваш pipeline уже использует его ✅
   - Это дополнительно помогает с дисбалансом

4. **Попробуйте разные варианты**
   - Начните с консервативного
   - Если F1 на классах 0/2 < 50%, переходите к агрессивному
   - Если овerfitting, вернитесь к сбалансированному
