# DeepLOB Training Project

Проект для обучения модели DeepLOB на данных стакана заявок.

## Структура проекта

```
orderBookTrain/
├── src/                    # Исходный код
│   ├── __init__.py        # Инициализация пакета
│   ├── config.py          # Конфигурация
│   ├── load_data.py       # Загрузка данных
│   ├── tools.py           # Утилиты (метки, окна)
│   ├── model.py           # Модель DeepLOB
│   ├── dataset.py         # Dataset и Sampler
│   ├── trainer.py         # Обучение модели
│   ├── focal_loss.py                 # Focal Loss
│   ├── cost_sensitive_loss.py        # Cost-Sensitive Loss
│   └── cost_sensitive_focal_loss.py # Cost-Sensitive Focal Loss
├── notebooks/             # Jupyter notebooks
│   └── pipeline.ipynb     # Основной pipeline
├── train.py               # Python скрипт для обучения
├── run_experiments.py     # Скрипт для запуска экспериментов
├── example.py             # Пример последовательного обучения
├── requirements.txt       # Зависимости Python
└── README.md              # Этот файл
```

## Использование

### 1. Обучение через Jupyter Notebook

Откройте `notebooks/pipeline.ipynb` и выполните ячейки по порядку. Notebook использует модульную структуру и позволяет легко экспериментировать с параметрами.

### 2. Обучение через Python скрипт

```bash
# Базовое обучение на одном дне
python train.py --train_dates="2025-09-22"

# Обучение на нескольких днях последовательно
python train.py \
    --train_dates="2025-09-22,2025-09-23,2025-09-24" \
    --val_date="2025-09-25" \
    --test_date="2025-09-26" \
    --epochs=15

# С кастомными параметрами
python train.py \
    --train_dates="2025-09-22,2025-09-23" \
    --val_date="2025-09-24" \
    --test_date="2025-09-25" \
    --epochs=20 \
    --batch_size=256 \
    --learning_rate=5e-4 \
    --hidden_size=256 \
    --save_path="my_model.pt"
```

### 3. Быстрый пример

```bash
# Запуск примера последовательного обучения
python example.py
```

### 4. Эксперименты с разными конфигурациями

```bash
# Запуск скрипта для экспериментов
python run_experiments.py
```

### 5. Доступные параметры

#### Параметры данных
- `--train_dates`: Список дат для обучения через запятую (по умолчанию: "2025-09-22")
- `--val_date`: Дата для валидации (по умолчанию: "2025-09-23")
- `--test_date`: Дата для тестирования (по умолчанию: "2025-09-24")
- `--data_folder`: Папка с данными (по умолчанию: "data")
- `--instrument`: Инструмент (по умолчанию: "Si-12.25")

#### Параметры модели
- `--tick_size`: Размер тика инструмента (по умолчанию: 1.0)
- `--theta_ticks`: Порог в тиках (по умолчанию: 5)
- `--horizon_sec`: Горизонт в секундах (по умолчанию: 2.0)
- `--window_length`: Длина окна (по умолчанию: 240)
- `--hidden_size`: Размер скрытого слоя (по умолчанию: 128)
- `--dropout`: Коэффициент dropout (по умолчанию: 0.3)
- `--use_cost_sensitive_focal`: Использовать Cost-Sensitive Focal Loss (по умолчанию: True)
- `--use_cost_sensitive`: Использовать только стоимостно-чувствительный лосс (по умолчанию: False)
- `--use_focal_loss`: Использовать только Focal Loss (по умолчанию: False)
- `--focal_gamma`: Gamma для Focal Loss (по умолчанию: 2.0)
- `--focal_alpha_weight`: Alpha weight для Focal Loss (по умолчанию: 0.25)
- `--cost_weight`: Вес cost-sensitive компоненты (по умолчанию: 1.0)

#### Параметры обучения
- `--batch_size`: Размер батча (по умолчанию: 512)
- `--learning_rate`: Скорость обучения (по умолчанию: 1e-3)
- `--epochs`: Количество эпох (по умолчанию: 15)
- `--seed`: Семя для воспроизводимости (по умолчанию: 42)

#### Параметры сохранения
- `--save_path`: Путь для сохранения модели (по умолчанию: "best_deeplob_like.pt")
- `--verbose`: Выводить подробную информацию (по умолчанию: True)

## Модули

### config.py
Содержит классы конфигурации для данных, модели и обучения. Позволяет легко настраивать параметры через код или аргументы командной строки.

### load_data.py
Функции для загрузки данных из файлов .npy и .csv.

### tools.py
Утилиты для построения меток (triple-barrier) и создания временных окон.

### model.py
Реализация модели DeepLOB с временными сверточными блоками.

### focal_loss.py
Focal Loss для решения проблемы дисбаланса классов.

### cost_sensitive_loss.py
Стоимостно-чувствительная функция потерь для финансовых данных с матрицей стоимости ошибок.

### cost_sensitive_focal_loss.py
Комбинированная функция потерь, объединяющая Cost-Sensitive Loss и Focal Loss для лучшего качества обучения.

### dataset.py
Dataset и сбалансированный sampler для обучения с равным представлением классов в батчах.

### trainer.py
Класс Trainer для обучения модели с поддержкой валидации, сохранения лучших состояний и тестирования.

## Последовательное обучение на нескольких днях

Проект поддерживает обучение модели на нескольких днях последовательно:

1. **Обучение**: Модель обучается на каждом дне из списка `train_dates` по заданному количеству эпох
2. **Сохранение**: После каждого дня обучения модель сохраняется в файл `model_day_N.pt`
3. **Валидация**: На каждом дне обучения используется один и тот же день валидации
4. **Тестирование**: Финальное тестирование выполняется на отдельном дне

### Пример последовательного обучения

```bash
python train.py \
    --train_dates="2025-09-22,2025-09-23,2025-09-24" \
    --val_date="2025-09-25" \
    --test_date="2025-09-26" \
    --epochs=15
```

Этот скрипт:
1. Обучит модель на 15 эпохах на данных 2025-09-22, сохранит в `model_day_1.pt`
2. Обучит модель на 15 эпохах на данных 2025-09-23, сохранит в `model_day_2.pt`
3. Обучит модель на 15 эпохах на данных 2025-09-24, сохранит в `model_day_3.pt`
4. Выполнит валидацию на данных 2025-09-25
5. Выполнит тестирование на данных 2025-09-26
6. Сохранит финальную модель в `best_deeplob_like.pt`

## Cost-Sensitive Focal Loss

Проект использует комбинированную функцию потерь `CostSensitiveFocalLoss`, которая объединяет преимущества:

1. **Cost-Sensitive компонента**: Учитывает различную стоимость ошибок
2. **Focal Loss компонента**: Борется с дисбалансом классов

### Матрица стоимости

```
C = [[0.0,  0.75, 1.0],   # Истина: down
     [0.5,  0.0,  0.5],   # Истина: flat  
     [1.0,  0.75, 0.0]]   # Истина: up
```

### Примеры использования

```bash
# Cost-Sensitive Focal Loss (по умолчанию)
python train.py --train_dates="2025-09-22,2025-09-23"

# Настройка параметров Cost-Sensitive Focal Loss
python train.py --train_dates="2025-09-22,2025-09-23" \
    --focal_gamma=2.5 \
    --focal_alpha_weight=0.3 \
    --cost_weight=0.8

# Только стоимостно-чувствительный лосс
python train.py --train_dates="2025-09-22,2025-09-23" --use_cost_sensitive

# Только Focal Loss
python train.py --train_dates="2025-09-22,2025-09-23" --use_focal_loss
```

## Преимущества новой структуры

1. **Модульность**: Каждый компонент выделен в отдельный модуль
2. **Переиспользование**: Код можно легко использовать в других проектах
3. **Конфигурируемость**: Все параметры настраиваются через конфигурацию
4. **Гибкость**: Легко переключаться между Jupyter и Python скриптами
5. **Расширяемость**: Просто добавлять новые модели или методы обучения
6. **Последовательное обучение**: Поддержка обучения на нескольких днях с сохранением промежуточных состояний
7. **Cost-Sensitive Focal Loss**: Комбинированная функция потерь с учетом стоимости ошибок и дисбаланса классов
